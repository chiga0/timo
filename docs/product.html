TIMO PRD & DESIGN SYSTEM · v0.2 MONOCHROME

首版产品设计与极简黑白交互规范

Timo 是本地优先的个人研发与运维交付控制面。独立 Web 工作台采用 Tailwind CSS + shadcn/ui Zinc 极简黑白体系，把注意力留给业务承诺、跨仓交付、红线审批与独立核验结果；底层绝不自研 Agent Loop，直接复用成熟外部执行器。

1. 核心产品机制

注意力防火墙（4 条硬约束）

执行过程物理隔离在右侧检查器；只有「红线待决 / 已核验交付 / 不可收敛阻塞」3 类事件穿透进主对话与收件箱；收件箱按任务原地 Upsert，禁止子任务刷屏。

总助理分级委派授权

用户配置常设委派策略（Standing Policy）与红线清单。开发/预发只读与开发仓 PR 由总助理静默放行并记审计流；仅生产发布、合并主干、生产敏感查询等红线弹审批卡。

两级 Watchdog + 实时透视

一级 0-Token 看门狗盯心跳停滞、死循环与范围漂移；异常时唤醒总助理自动纠偏或换执行器。用户随时可在检查器切至「实时运行流」透视原生执行并人工纠偏。

2. 极简黑白设计系统（95% 黑白灰 + 5% 语义微信号）

进行中 / 等待 CI

纯黑/纯白中性语义，安静后台推进，不打扰用户。

红线待决 / 临期

6px 琥珀微点，置顶关注，明确展示范围与有效期。

未知 / 失败 / 禁止

6px 红点或细红边框警示，禁止盲重试，引导核对。

已独立验收

6px 绿点收口，每条证据可点击展开冻结原文与摘要。

3. 信息架构与交互原则

区域 / 交互职责与设计原则
极简二栏 + 主视图切换整页锁定 100dvh 消除双滚动条，彻底移除拥挤的右侧窄抽屉；左侧导航栏支持 [ 一键折叠，右侧宽敞主工作区在「主对话 / 单任务详情页 / 设置」三个视图间清晰切换；底部输入框采用图标+名称的代理/模型选择器与「自动匹配工作区」开关，高级覆盖项按需折叠。
固定主对话 + 单卡实时演进默认进入全局唯一的「用户 ↔ Timo 总助理」流式主对话（真 SSE 逐字输出 + 成熟 GFM Markdown / 表格 / 代码高亮 / Mermaid 矢量图 + 0ms 乐观上屏）；闲聊与只读查询直接回复绝不污染任务列表；派发的后台工程任务在主对话中以单张实时演进的任务卡呈现：运行中展示单行最新进度，完成后直接在卡片内渲染限高（~240px + 渐隐遮罩 + 展开/收起）的 Markdown 最终结论，不重复追加气泡。
固定「待我处理」与任务管理左侧栏依次为「主对话」「固定置顶的待我处理（仅红线审批/阻塞失败/效果未知，已完成绝不入待办）」「后台任务列表（支持重命名/归档/删除与活跃/已归档切换）」和底部「设置」。
单任务详情页（以任务为中心）点击主对话任务卡「查看详情 →」或左侧任务项时，主区切换为宽屏单任务详情页（顶部 ← 返回主对话 + 标题重命名 + 停止/重试/归档/删除）；左主栏展示完整不截断的 Markdown/Mermaid 最终结论、实时执行进展流与运行中纠偏（Steer）；右证据栏收纳原始需求、代码改动/MR/CI、折叠式独立验收输出与跨执行器交接（Handoff）。
独立设置视图（工作区与凭证隔离）按「通用（外观）/ 开发（主助手与代理、统一工作区与受管 Worktree、平台与本地/独立凭证）/ 系统（安全护栏与状态）」分组收纳；密钥独立存于 0600 保险箱，绝不进知识库或执行器。
